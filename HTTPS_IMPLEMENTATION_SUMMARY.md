## 🚀 How to Use

### Development Environment

#### Quick Start
```bash
# Set up HTTPS for development (one-time setup)
npm run setup:dev

# Start with HTTPS enabled
npm run start:https
# OR
ENABLE_HTTPS=true npm run start:dev
```

#### Access Points
- **HTTPS**: https://localhost:3443/api/v1/
- **HTTP Fallback**: http://localhost:3000/api/v1/ (if HTTPS disabled)

```bash

```

### 2. Security Headers (Helmet.js)
```typescript
helmet({
  contentSecurityPolicy: production ? undefined : false,
  crossOriginEmbedderPolicy: production,
  hsts: production ? {
    maxAge: 31536000,
    includeSubDomains: true,
    preload: true,
  } : false,
})
```

### 3. CORS Configuration
```typescript
enableCors({
  origin: [frontendUrl, 'https://localhost:3443', ...],
  methods: ['GET', 'POST', 'PUT', 'DELETE', 'PATCH', 'OPTIONS'],
  allowedHeaders: ['Authorization', 'Content-Type', ...],
  exposedHeaders: ['Authorization', 'X-Access-Token', ...],
  credentials: true,
})
```

### 4. Input Validation
```typescript
useGlobalPipes(
  new ValidationPipe({
    whitelist: true,
    transform: true,
    forbidNonWhitelisted: true,
  }),
)
```

### 5. JWT Security
- **Short expiry**: 15 minutes (configurable)
- **Secure secrets**: Environment-based configuration
- **Issuer/Audience validation**: Prevents token misuse
- **Bearer token extraction**: From Authorization header

## ⚠️ Important Security Notes

### Development
- Self-signed certificates will show browser warnings (normal)
- Use strong secrets even in development
- Never commit .env files to version control

### Production
- Use valid SSL certificates (Let's Encrypt recommended)
- Generate strong, unique secrets (64+ characters)
- Enable HSTS and other production security features
- Set up certificate auto-renewal
- Monitor certificate expiration

## 🔄 Migration from HTTP to HTTPS

Your existing API endpoints remain the same, just accessed via HTTPS:
- **Before**: `http://localhost:3000/auth/login`
- **After**: `https://localhost:3443/api/v1/auth/login`

Note the API versioning prefix (`/api/v1/`) is also added for better API organization.

## 📈 Performance Impact

The security implementations have minimal performance impact:
- **Helmet.js**: < 1ms overhead per request
- **CORS**: Negligible overhead
- **Validation**: Only on requests with bodies
- **HTTPS**: ~2-5ms SSL handshake (cached after first request)
